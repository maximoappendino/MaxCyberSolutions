● How it works:

  1. Renders one set of logos, waits for images to actually load (so dimensions
  are real)
  2. Measures the true pixel width of that set + one gap
  3. Clones it exactly as many times as needed to fill 4× the viewport — no
  hardcoded count
  4. Sets --marquee-dist on the track so the CSS animation moves by precisely
  one set, then loops back to pixel 0

  Result: no white spaces, no matter how few clients there are.
